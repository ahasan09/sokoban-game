# Sokoban Game

Browser-based Sokoban puzzle game implemented in vanilla JavaScript with sprite assets.

## Tech Stack
- HTML5 (Canvas or DOM)
- CSS3
- Vanilla JavaScript
- Sprite image assets

## Project Structure
```
sokoban_game/
├── index.html
├── app.js
├── style.css
└── assets/           # Sprite images
```

## Development
No installation required. Open `index.html` directly in a browser:
```bash
open sokoban_game/index.html
```

## Key Notes
- No build step or dependencies — fully self-contained static files.
- Player pushes boxes onto target squares using arrow keys.
